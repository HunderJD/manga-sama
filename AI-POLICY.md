# AI policy

manga-sama itself was written with the help of AI, so using it is fine.
What matters is that a human understands every line and stands behind it.

## ✅ Fine

- Using AI to understand the code, track down a bug or try an idea, as long as you check what it tells you.
- Using AI to write code, if you can explain every line of it: what it does, and why it's written that way.
- Saying in your pull request that you used AI, and for what. That's expected, and it's not a reason to refuse it.

## ❌ Not fine

- Code you can't explain. If the answer to "why this line?" is "the AI wrote it", the pull request gets closed.
- Vibe coding: piling up generated code until it compiles, without understanding it.
- Ignoring the basics: huge functions, copy-paste, abstractions nobody needs. Try to follow SOLID, and keep it simple.
- Pull requests or issues opened by an AI agent on its own, with no human behind them.
- Using AI to rewrite code whose license isn't compatible with MIT.

## Otherwise

The pull request is closed, no hard feelings. Fix it and send it again.
